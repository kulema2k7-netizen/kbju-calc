# 🥗 NutriPlan КБЖУ

Лёгкое веб-приложение для подсчёта калорий, белков, жиров и углеводов. Работает в браузере и устанавливается на телефон как PWA. Весь код лежит в одном файле `index.html`, сервер и регистрация не нужны.

Все данные хранятся только на вашем устройстве, в `localStorage` браузера.

## Возможности

**Расчёт нормы**
- Параметры: пол, возраст, рост, вес, уровень активности, цель (снижение веса −15%, поддержание, набор массы +15%).
- Суточная норма калорий по формуле Миффлина — Сан-Жеора. Белок считается из расчёта 1,8 г на кг веса, жиры составляют 25% калорий, остальное идёт на углеводы.
- Индекс массы тела с цветовой отметкой.

**Активность**
- В блоке «🔥 Активность» можно вписать, сколько всего калорий вы сожгли за день (вместе с калориями покоя), например по данным часов или браслета.
- Если значение вписано, норма калорий этого дня равна сожжённым калориям с учётом цели (например, −15% при снижении веса). Если нет, действует обычная норма по параметрам.
- Сводка за 7 дней и общий анализ сравнивают каждый день с его собственной нормой.

**Дневник питания**
- Приёмы пищи: завтрак, обед, ужин, перекус.
- Учёт по дням: у каждого дня свои записи, в полночь начинается новый день. Стрелками ◀ ▶ можно листать прошлые дни, смотреть и править их.
- Итоги за день с полосами прогресса по калориям, белкам, жирам и углеводам.
- Сводка за последние 7 дней относительно нормы.

**Продукты и блюда**
- Список продуктов, к которому можно добавлять свои. Вес порции задаётся в граммах.
- Быстрая база из 143 популярных продуктов и блюд. Поиск идёт по словам и понимает окончания: запрос «хлеб с ветчиной» найдёт бутерброды.
- Поиск в интернете по базе Open Food Facts.
- Составные блюда: например, хлеб + масло + ветчина = бутерброд. Блюдо добавляется в дневник по штукам.

**Подсказки и подбор**
- В каждой вкладке приёма пищи показывается, что добавить: продукты из вашего списка с граммовкой под оставшуюся норму дня.
- Блок «🔎 Подобрать по БЖУ»: впишите, сколько белков, жиров или углеводов нужно набрать (или нажмите «Подставить остаток на сегодня»), и приложение предложит продукты с граммовкой.

**Вес и анализ**
- Запись веса по датам, целевой вес, график изменения.
- Общий анализ за 7 дней, 30 дней или всё время. Он показывает средние калории и БЖУ в процентах от нормы, что вы систематически недобираете или перебираете, темп изменения веса и оценку срока до цели.

**Удобство**
- Редко нужные блоки сворачиваются: параметры (ИМТ остаётся виден), активность, добавление продукта, подбор по БЖУ, составное блюдо, вес и последние 7 дней. При первом запуске они свёрнуты, а выбранное состояние запоминается. Итоги за день, рацион и общий анализ всегда открыты.

**Резервная копия**
- Кнопки «Выгрузить данные» и «Загрузить данные» сохраняют и восстанавливают параметры, свои продукты, всю историю дневника, вес и сожжённые калории в одном JSON-файле. Это удобно для переноса на другое устройство.

## Быстрый старт

1. Скачайте репозиторий или откройте `index.html` в браузере. Для установки как приложения и работы service worker нужен адрес `https://` или `localhost`.
2. Заполните «Ваши параметры».
3. Выберите приём пищи, продукт и вес, нажмите «+ Добавить».

### Публикация на GitHub Pages

1. Положите в корень репозитория файлы `index.html`, `manifest.json` и `sw.js`.
2. В репозитории откройте **Settings → Pages**, выберите ветку (например, `main`) и папку `/ (root)`, сохраните.
3. Через минуту-две приложение откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.
4. На телефоне откройте ссылку в браузере и выберите «Установить приложение» или «Добавить на главный экран».

После обновления `index.html` установленное приложение иногда нужно закрыть и открыть заново, чтобы подтянулась новая версия.

## Технологии

- HTML, CSS и чистый JavaScript без сборки и зависимостей
- [Tailwind CSS](https://tailwindcss.com) (подключён с CDN)
- `localStorage` для хранения данных
- [Open Food Facts](https://world.openfoodfacts.org) для поиска продуктов в сети

## Данные и приватность

- Данные не отправляются ни на какой сервер. Исключение: при нажатии «Найти в сети» название продукта уходит в запрос к Open Food Facts.
- Данные привязаны к браузеру и адресу сайта. Если очистить данные сайта или сменить устройство, они пропадут, поэтому периодически делайте выгрузку резервной копии.

Формат резервной копии (JSON):

```json
{
  "app": "nutriplan",
  "version": 4,
  "profile": {},
  "foods": [],
  "days": { "2026-10-15": { "breakfast": [], "lunch": [], "dinner": [], "snack": [] } },
  "weights": { "2026-10-15": 85.0 },
  "burned": { "2026-10-15": 2600 },
  "targetWeight": 80
}
```

Файлы старых версий (без истории по дням) тоже загружаются: их данные записываются как записи за сегодня.

## Ограничения

- Значения КБЖУ в быстрой базе усреднённые. У конкретной упаковки или блюда они могут отличаться, свои значения всегда можно ввести вручную.
- Подсказки и анализ строятся по формулам и вашим записям. Это не медицинская рекомендация и не замена консультации врача или диетолога.
- Tailwind загружается с CDN, поэтому без интернета оформление может не отобразиться. Для полностью офлайн-работы стили стоит собрать локально.
- Фото блюда приложение не распознаёт.
